Method

  • 10 public issues from 3 mid-size repositories, each carrying a label or comment indicating the maintainer asked for more information.
  • Two conditions per issue: the original report as posted, and a ReproKit report generated from it. Identifying details stripped from both.
  • 3 raters, each timed, order randomised to avoid practice effects.
  • Task: “Can you reproduce this from what's written? If yes, start now. If no, say what you'd ask for.”
  • Time capped at 8 minutes; anything unresolved counts as abandoned as unfollowable.
  • Failure is reported as failure. If ReproKit does worse on any issue, that issue stays in the table.

Raw data and the exact harness live in the repository under benchmark/.
